# BIOREZA official identity assets

The lockups in this directory are geometry-preserving, transparent crops of the
official delivery artboards in `../../bioreza-logo-clean-up-2/`.

- `bioreza-lockup-dark.png`: Artboard 4, wide main-text lockup for light surfaces.
- `bioreza-lockup-light.png`: Artboard 18, wide light lockup for dark surfaces.
- `bioreza-lockup-soft-gold.png`: Artboard 20, wide soft-gold lockup for dark surfaces.
- `bioreza-mark-dark.png`: the official O/lotus mark cropped from Artboard 3.
- `bioreza-og.jpg`: derived social canvas using the official palette and lockup.

No logo paths, proportions, spacing, or letterforms are redrawn. Background
removal, trimming, and output optimization are the only asset-processing steps.

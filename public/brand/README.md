# BIOREZA official identity assets

The lockups in this directory are geometry-preserving, transparent crops of the
official delivery artboards in `../../bioreza-logo-clean-up-2/`.

- `bioreza-lockup-dark.png`: current wide lockup in the restored heritage-gold palette.
- `bioreza-lockup-light.png`: current wide lockup in the restored heritage-gold palette.
- `bioreza-lockup-soft-gold.png`: compatibility variant using the same heritage-gold palette.
- `bioreza-mark-dark.png`: current O/lotus mark in the restored heritage-gold palette.
- `bioreza-og.jpg`: derived social canvas using the official palette and lockup.

No logo paths, proportions, spacing, or letterforms are redrawn. The current
geometry is preserved pixel-for-pixel; every visible pixel uses the single flat
historical antique-gold color `#8F6914`, without gradients or metallic effects.
